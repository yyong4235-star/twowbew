## Netlify 部署

1. 登录 Netlify。
2. 点击 `Add new site`。
3. 选择 `Import an existing project`。
4. 连接 GitHub，并选择公司官网仓库。
5. 构建设置：
   - Build command：留空。
   - Publish directory：留空或填项目根目录。
6. 点击 `Deploy site`。
7. 部署完成后，先用 Netlify 临时域名检查官网。

## Netlify Identity 和 Git Gateway

1. 进入 Netlify 站点后台。
2. 打开 `Site configuration`。
3. 找到 `Identity` 并启用 Identity。
4. Registration 设置为 `Invite only`。
5. 打开 `Services`。
6. 启用 `Git Gateway`。
7. 邀请管理员邮箱。
8. 管理员接受邀请并设置密码。
9. 访问 `https://你的域名/admin/` 登录后台。

## 后台使用

后台入口：

```text
https://你的域名/admin/
```

后台主要分为三组内容：

- `Site Settings`：修改公司信息、电话、邮箱、地址、logo、首页背景图、关于我们大图、各页面图片。
- `Page Content`：修改越南文、英文、中文页面文案。
- `Privacy Policy`：修改三语隐私政策。

保存内容后，Netlify 会自动提交内容改动并重新部署。通常等待几十秒到几分钟，线上网站就会更新。

## 常见问题

### 直接打开 HTML 后页面不显示

后台版前台会读取 `content/*.json`，直接用 `file://` 打开时浏览器可能禁止读取 JSON。请用本地服务器或线上域名访问。

### 后台打不开或登录失败

检查 Netlify 是否已经启用：

- Identity
- Invite only 注册方式
- Git Gateway

同时确认访问的是线上 `/admin/`，本地 `/admin/` 只能用于检查后台页面和配置，不等同于线上登录环境。

### 后台保存后前台没变化

先到 Netlify Deploys 页面查看是否触发了新部署。如果没有触发，检查 Git Gateway 是否启用。如果已经部署成功，浏览器强制刷新页面。
